# Asmita Mahadik — Portfolio

Personal developer portfolio and case studies.

**Live:** [portfolio25-asmita-mahadik.vercel.app](https://portfolio25-asmita-mahadik.vercel.app/)

## Tech Stack

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) (via [Vite](https://vitejs.dev/))
- [Tailwind CSS](https://tailwindcss.com/) with [shadcn/ui](https://ui.shadcn.com/) components
- [React Router](https://reactrouter.com/)

## Local Development

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:8080`.

## Build

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
├── components/
│   ├── layout/      # Navigation, particles background, floating dock
│   ├── sections/    # Hero, About, Projects, Skills, Experience, Contact
│   └── ui/          # shadcn/ui primitives
├── data/            # Project and skill content
├── hooks/
└── pages/
```
